# **PROJETO JUQUERY**

O Projeto Juquery, é um software de monitoramento e gerenciamento de sensores anti-chamas, com propósito de 
previnir e evitar queimadas florestais.

## 🚀Principais Funcionalidades

• CRUD de Usúarios e Sensores
• Informações do tempo e clima local
• Geolocalização em tempo real
• Envio de alertas

## 🌱Objetivo

O projeto tem como principio, a sustentabilidade e prevenção de desastres naturais, inspirada nos grandes 
impactos das queimadas florestais não só no Brasil como no mundo inteiro. Um projeto acadêmico planejado 
para ajudar o corpo de bombeiros no combate a esses tipos de desastres.

## ⚙️Técnologias 

• Java SE 
• Kotlin
• SQLite
• Api's rest ( MapBox, OpenWheater)
